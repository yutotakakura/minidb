## この Phase で理解すること

- **DB の性能はほぼ「ディスクに何回行ったか」で決まる。** メモリを 1 秒とすると SSD は約 17 分
- **だから性能の単位は「行数」ではなく「触ったページ数」。** 1 行欲しくても 4KB 丸ごと読む
- **インデックスの正体はこれだけ。** 1 万行なら Seq Scan は 245 ページ、Index Scan は 3〜4 ページ
- **スロット経由の間接参照が RID の安定性を支える。** ページ内で行を動かしてもインデックスを壊さない
- **削除が墓標なのは意図的。**「DELETE してもファイルが小さくならない」の正体
- **pin が無いと、貸し出し中のページが別ページに化ける。** 静かにデータが壊れる
